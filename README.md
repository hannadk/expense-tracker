# Expense Tracker

Simple income / expense / investment tracker. Works on any phone, installs like an app, works offline, downloads Excel reports. Data stays on the device (browser storage).

## Put it online for free (GitHub Pages)
1. Create a free account at github.com and click New repository (name e.g. expense-tracker, Public).
2. Click "uploading an existing file", drag in ALL files from this folder (index.html, manifest.json, sw.js, both icons, xlsx.full.min.js), then Commit.
3. Repository Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root), Save.
4. After about a minute your link is https://YOUR-USERNAME.github.io/expense-tracker/

## Install on a phone
- iPhone (Safari): Share > Add to Home Screen
- Android (Chrome): menu > Install app

## Notes
- First visit: create your own access code. Each device keeps its own data and its own code.
- Download the Excel report regularly as a backup.
- Open source: free to edit and share.
